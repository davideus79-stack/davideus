# MyHome

Note e file dal tuo iPhone al tuo PC, all'istante.

- Scrivi una nota o carica foto, video, Word, Excel, PDF dal telefono: compaiono subito sul PC (e viceversa).
- Ognuno entra con la sua email e vede solo le sue cose.
- Puoi cancellare un elemento o tutto quanto dal menu.
- Cinque stili grafici (Aurora, Notte, Carta, Tramonto, Oceano), da cambiare quando vuoi dal menu.

## Come si installa sull'iPhone

1. Apri il link dell'app con **Safari**.
2. Tocca il pulsante **Condividi** (il quadrato con la freccia).
3. Scegli **Aggiungi alla schermata Home**.

Sul PC basta aprire lo stesso link con il browser (Chrome o Edge permettono anche di installarla come app).

## Come è fatta

- Pagina web statica (HTML, CSS, JavaScript), pubblicata gratis con GitHub Pages.
- Dati, file, accessi e aggiornamenti in tempo reale su Supabase (piano gratuito).
- Limiti del piano gratuito: 1 GB di spazio, 50 MB per file; il progetto va in pausa dopo 7 giorni senza uso.
